# Public Square

An initial responsive home screen for exploring community priorities. Uses clearly labeled illustrative US location data, with working National / State / City / ZIP location controls, topic, and text filters, reset, and concern detail dialogs. No backend or accounts are connected.

## Run locally

From this directory:

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

Open port 3000 in your development browser. No package installation or build is required. Google Fonts are optional; system sans-serif fonts are used if unavailable.
